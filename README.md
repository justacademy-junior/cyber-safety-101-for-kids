# Cyber Safety 101: What Every Child Should Learn Online

A fun, interactive landing page that teaches children the basics of internet safety. Kids play a quick Safe or Sketchy game with Byte the safety bot, learn five easy rules and test a practice password. Parents get a clear path to the full guide.

## What is inside

- **Safe or Sketchy game:** six real life scenarios with instant feedback and a score.
- **Five safety rules:** Pause, Protect, Polite, People you know and Parent power.
- **Password lab:** a practice strength meter. It never stores or sends anything.
- **Responsive design:** works on phones, tablets and desktops, with light and dark mode and reduced motion support.

## Run it locally

Download `index.html` and open it in any browser. There is nothing to install.

## Publish on GitHub Pages

1. Create a new repository and upload `index.html` and `README.md`.
2. Open **Settings**, then **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and the `/ (root)` folder, then save.
4. Your page goes live at `https://<your-username>.github.io/<repository-name>/` within a minute or two.

## Customise

All colours live in the `:root` block at the top of the `<style>` tag. The game questions sit in the `Q` array inside the script, so you can add or edit scenarios in one place.
